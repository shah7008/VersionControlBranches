# Version Control Branches

A university collaboration exercise created to practice Git version control, branching, and collaborative development workflows.

The repository contains contributions from multiple participants and demonstrates how different files and changes can be added and updated within a shared Git repository.

## 📚 Concepts Practiced
Git repositories
Branches
Adding and updating files
Collaborative development
Pulling and pushing changes
Tracking changes with commits
Working with a shared repository
## 📁 Repository Contents
### Teacher / Practical Demonstration
Greetings.py — example file used for demonstrating a new feature.
LocalVariable.py — example file used for demonstrating file updates.
### My Contributions
Study_planner.py — study planner application.
Sql_simulator.py — SQL simulator application.
study_planner.db — SQLite database for the study planner.
simulator.db — SQLite database for the SQL simulator.
## 🛠️ Technologies
Git
GitHub
Python
SQLite
## 🎓 Project Context

This repository was created as part of university coursework to practice version control and collaboration using Git and GitHub.

The exercise provided experience with working in a shared repository, managing branches, committing changes, and contributing project files alongside other developers.
